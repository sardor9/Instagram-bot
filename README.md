# 📸 Instagram Downloader Bot (Telegram)

Этот проект — **Telegram bot**, и если вы отправите ему ссылку Instagram `post/reel/tv` - он вернет медиа (фото/видео) и описание сообщения. 
Bot **[aiogram](https://docs.aiogram.Дев/) * * и * * [инстаграпи](https://github.com/adw0rd/instagrapi) использует библиотеки**.

---

## 🚀 Setup

### 1. Открой Command Prompt или PowerShell 
Клонируй репозиторий:
```bash
git clone https://github.com/<username>/instagram-downloader-bot.git
cd instagram-downloader-bot
```
**2. Создай и активируй виртуальное окружение:**
``` bash
python -m venv venv
source venv/bin/activate   # Linux/MacOS
venv\Scripts\activate      # Windows
```
**3. Установка библиотек**
``` bash
pip install -r requirements.txt
```
**4. Создать файл .env**
``` ini
TELEGRAM_BOT_TOKEN=telegram_bot_tokeningiz
IG_USERNAME=instagram_username
IG_PASSWORD=instagram_password
```
**▶️ Usage запусти через командную строку:**
``` bash
python Instagrambot.py```
